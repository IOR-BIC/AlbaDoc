Detailed Description

Avatars are entities moving in the virtual world according to user's movements, and thus representing their presence in the virtual world.

Specialized classes must set the Avatar variable with a vtkProp3D, this class will take care of adding it to the current renderer, moving, hiding and showing it at the right time. The Avatar moves according to the device it observes, which must also be set by subclasses.
